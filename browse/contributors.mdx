Every song, credit, and artist profile on Diskograf is there because someone added it. The Contributors section is where you can see who's doing that work, browse the community, and get a sense of how the catalogue is growing.

## The Contributors Directory

Open the Contributors page from the main navigation to browse everyone who has contributed to Diskograf. You can search by name and sort the list by activity or by when someone joined.

Each entry links to a public profile showing:

- The contributor's display name, username, and profile photo.
- Their public contribution history.
- Any artist profile they've claimed, if applicable.

## Contributor Leaderboards

The community overview surfaces public leaderboards for recent activity, so you can see who has been most active in a given window. This is intended as a way to recognise the people keeping the catalogue current, not as a competition.

Leaderboards only include public contributions. Private profile edits and personal library changes are never counted.

## Contribution History on Profiles

Every contributor profile has a public contributions view listing the songs and artists they've touched, in reverse chronological order. This is the same data available through the [Public API](/developers/api) under `/v1/users/:username/contributions`.

See [Contribution History](/account/contribution-history) for what appears on your own profile and how it's presented.

## Becoming a Contributor

Any registered Diskograf account can contribute. There's no application process and no tiered role system for editors, only a single expectation: contribute accurately, cite where you can, and treat the catalogue as something other people rely on.

Start with [How to Contribute](/contribute/overview) if you're new.

<Note>
  If you'd rather stay anonymous while contributing, keep your username generic and your profile photo blank. Your contributions will still be credited to your account, but nothing on your profile identifies you outside Diskograf.
</Note>
