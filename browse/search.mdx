Search finds songs, artists, and labels fast. Plain text is enough to start. Filters narrow your results when you need precision.

## Basic Search

Type a word or phrase in the search bar to search song titles. Partial matches work. The most relevant results come first.

Ranking uses two signals:

- **Catalogue importance**: songs with more credit data rank higher.
- **YouTube activity**: songs with more YouTube engagement rank higher.

## Search Filters

Filters search beyond song titles. Each filter has a full form and a one-letter shorthand. Both work the same.

| Filter | Shorthand | Example | What it does |
|---|---|---|---|
| `artist:name` | `a:name` | `artist:siti` | Filter results to songs by a matching artist |
| `artist:"first last"` | `a:"first last"` | `artist:"siti nurhaliza"` | Match a multi-word artist name exactly (requires quotes) |
| `label:name` | `l:name` | `label:sony` | Filter results to songs released on a matching label |
| `year:YYYY` | `y:YYYY` | `year:2020` | Return songs released in that exact year |
| `decade:YYYY` | `d:YYYY` | `decade:1990` | Return songs released in any year of that decade |

### Artist name matching

Artist filters match partial names and known aliases. If an artist has several names, any of them matches.

### Label name matching

Label filters also match partial names. `label:rocket` matches Rocketfuel Entertainment Sdn Bhd.

## Combining Filters

You can mix plain text with any number of filters. Order does not matter.

```text
cinta artist:siti decade:2000
```

This returns 2000s songs with "cinta" in the title by an artist matching "siti".

More examples:

```text
artist:"faizal tahir" year:2008
```

```text
label:rocketfuel decade:1990
```

```text
wings label:padu
```

There is no limit on the number of filters.

## Search Tips

<AccordionGroup>
  <Accordion title="My search returned no results">
    Try these steps in order:

    1. **Remove filters one at a time.** `year:2005 label:sony artist:ella` may be too narrow. Remove the strictest filter first.
    2. **Check your spelling.** A typo in the first few letters can block a match.
    3. **Use a shorter term.** Try the most distinctive word from the title.
    4. **Use the artist filter alone.** `artist:name` shows the artist's full catalogue.
  </Accordion>
  <Accordion title="How do I search for a multi-word artist name?">
    Wrap the name in double quotes:

    ```text
    artist:"faizal tahir"
    ```

    Without quotes, each word is a separate term. `artist:faizal tahir` filters by "faizal" and adds "tahir" as plain text.

    Multi-word label names work the same way:

    ```text
    label:"suria records"
    ```
  </Accordion>
  <Accordion title="Can I search by decade instead of an exact year?">
    Yes. Use `decade:` (shorthand `d:`) with the first year of the decade:

    ```text
    decade:1980
    ```

    This returns songs from 1980 to 1989. It helps when you know the era but not the year.

    You can combine it with other filters:

    ```text
    artist:m.nasir decade:1990
    ```
  </Accordion>
  <Accordion title="Why do some artists appear higher in results?">
    Ranking uses **catalogue importance**, meaning how complete a record is. It also uses **YouTube activity**, meaning views and engagement. Well-documented artists with active YouTube channels rank higher than sparse entries.

    To find a lesser-known artist, use the `artist:` filter instead of plain text. It skips relevance ranking and returns all matching artists.
  </Accordion>
</AccordionGroup>
