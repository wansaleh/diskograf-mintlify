The Artists page is a searchable directory of Malaysian artists. Each profile shows the artist's songs and roles.

## Find an artist

You can reach an artist in three ways:

- **Artist directory**: open [Artists](https://diskograf.com/artists) and search.
- **Header search**: search artist names and aliases from any page.
- **Direct link**: unclaimed profiles use `diskograf.com/artist/{id}-{slug}`. A profile linked to a member account uses `diskograf.com/{username}`. The old artist URL redirects there.

## Filter the artist directory

The directory supports:

- Keyword search
- Credit-role filtering
- **Verified** or **Unclaimed** status filtering
- **Band** or **Solo** type filtering
- Sorting by name or song count
- Pagination

Combine filters to narrow the list.

## Artist profile pages

An artist profile can include:

- Profile image, name, aliases, and biography
- Group or solo status, location, and social links when available
- Genre breakdown
- Full discography with credited roles
- Associated acts, top collaborators, and labels when available

### Filter an artist's works

You can narrow the works grid by:

- Credit role
- One or more genres
- Collaborator: songs the artist shares with one other artist
- Label: songs released on one label, where the artist is the lead performer
- Keyword search

The sidebar lists the 10 artists this artist worked with most. Click one to see only their shared songs. The **Collaborator** filter lists every collaborator with a shared song count. Type a name to find one.

You can sort works by:

- Latest or oldest release
- YouTube views or views per day
- Title or catalogue order

Results are paginated. Active filters appear in the URL.

For example:

```text
diskograf.com/artist/{id}-{slug}?genre=ballad
diskograf.com/artist/{id}-{slug}?with={collaborator-artist-id}
```

## Artist aliases

Artists may use a stage name, short name, other spelling, or another alias. Diskograf indexes aliases, so any known name leads to the same profile.

For multi-word names, use quotes in the search filter:

```text
artist:"siti nurhaliza"
```

See the [Search reference](/browse/search) for the full search syntax.
